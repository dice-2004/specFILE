## 依頼文

```
あなたは仕様書のレビュワーです。添付の仕様書だけを読み、次の観点で確かめてください。

背景：<対象を一文で>。読み手は <読み手>、使い道は <使い道> です。

観点
1. 目的のどれにも結びつかない要件、どの要件にも結びつかない目的がないか。
2. すべての要件に完了の条件があり、第三者が合否を判定できるか。判定できない言葉（「適切に」「速やかに」「使いやすく」「など」の類）が残っていないか。
3. 要件同士、要件と前提・制約、要件と対象外の間に矛盾がないか。
4. 例外・エラー・権限・境界値の振る舞いが抜けていないか。
5. 用語の表記が揃っているか。未定義の用語がないか。
6. 人が読んでも AI が読んでも同じ内容が伝わるか。図や画像だけで示した内容、位置で指した参照（「上の表」「前述」）、節の番号や ID のない参照がないか。
7. この仕様書だけを渡されて実装・テストする担当者として、作り始める前に聞きたい質問を挙げてください。

出力
- 指摘を重要度順（高・中・低）に並べ、指摘ごとに「該当箇所（節・要件 ID）／問題／直し方の案」を書いてください。
- 7 の質問は別の一覧にしてください。
- 書き方の好み（言い回し、体裁）は省いてください。
- 問題がない観点は「問題なし」と一行で書いてください。
```

## 指摘の記録
