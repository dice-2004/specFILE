## 種類に合わせて節を足す

|---|---|

## 使い方の決まり

- Claude Docs で作るときは、テンプレートの見出しと表をそのまま文書に写す。リポジトリに置くときはファイルを写す。
- 山かっこ `<…>` と「例」の行を置き換え、HTML コメントは消す。
- 節は消さない。当てはまらない節は「該当なし（理由）」、別の文書に書いた節は「→ リンク」と書く。
- 文書を分けたら、本体の 0 の「文書一覧」に行を足し、分けた文書の先頭に本体へのリンクを置く。
- テンプレートを直したいときは、[ワークフロー](../docs/workflow.md) の「工房の整備」に従う。
