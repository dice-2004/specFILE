# 承認済みの仕様書の一覧

入口：[AGENTS.md](../AGENTS.md)

ここには、ユーザーが承認した版の仕様書を Markdown で置く。作成中の版は Claude Docs に置き、承認後に PR でここへ入れる（手順は [ワークフロー](../docs/workflow.md) の 7）。

## 置き方

- 仕様書 1 件につき `specs/<対象の略名>/` を作り、入口の文書を `spec.md` とする。
- 文書を分けた場合は同じフォルダに置き、`spec.md` の文書一覧からリンクする。
- 子の仕様書は `specs/<親の略名>/<部品の略号>/spec.md` に置く。
